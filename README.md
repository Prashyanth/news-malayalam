# 📰 News Malayalam

**Your favourite Malayalam news channels, all in one place.**

News Malayalam is a web-based live news streaming platform that brings popular Malayalam news channels together in a single, clean and user-friendly interface.

🌐 **Live Website:** https://prashyanth.github.io/news-malayalam/

## ✨ Features

- Watch multiple Malayalam news channels in one place.
- YouTube live-stream integration.
- Switch between channels easily.
- Channel logos and dedicated channel cards.
- Responsive, dark-themed interface.
- Simple and user-friendly design.

## 📺 Available Channels

- Asianet News
- 24 News
- Manorama News
- Mathrubhumi News
- MediaOne
- Reporter TV

*Live-stream availability depends on the respective channels' YouTube broadcasts.*

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prashyanth/news-malayalam.git
   ```

2. Navigate to the React project:

   ```bash
   cd news-malayalam/news-malayalam-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🌐 Deployment

This project is deployed using GitHub Pages.

To build and deploy updates:

```bash
npm run deploy
```
